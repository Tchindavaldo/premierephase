## Ce que c'est
Outil qui retire automatiquement l'alignement de sécurité (les refus) des modèles de langage open source
(Qwen, Gemma, Mistral, gpt-oss…). Il utilise l'*abliteration* (Arditi et al. 2024) : on repère la « direction »
des refus dans le réseau, puis on la retire des poids. Il n'y a pas de réentraînement.
Un optimiseur (Optuna, méthode TPE) cherche les meilleurs réglages pour avoir le moins de refus possible
tout en restant proche du modèle d'origine (mesuré par la divergence KL).

## Comment y accéder / l'installer
```sh
pip install -U heretic-llm          # nécessite Python 3.10+ et PyTorch 2.2+
heretic Qwen/Qwen3-4B-Instruct-2507
# ou, depuis le dépôt cloné :
git clone https://github.com/p-e-w/heretic && cd heretic && uv run heretic --help
```
Matériel conseillé : GPU NVIDIA avec 16 Go de VRAM ou plus (environ 45 min pour un modèle de 4B sur une RTX 3090).

## Verdict
Fonctionnel, bien maintenu, c'est l'outil de référence (plus de 5000 modèles publiés avec).
Utile pour la recherche sur l'alignement ou pour un modèle qui refuse trop de demandes légitimes.
Attention : le modèle obtenu n'a plus de garde-fous, l'utilisateur est responsable de son usage.
